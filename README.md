# ScrollCapture (Rust Edition) • by @Carist 🦀

Нативное, сверхбыстрое и минималистичное приложение на языке **Rust** для создания длинных скриншотов с автопрокруткой и обычных снимков выделенной области.

---

## ⌨️ Горячие клавиши (работают в трее и в любом окне)

| Сочетание клавиш | Действие |
|---|---|
| **`Ctrl + Shift + S`** | **Снимок с автопрокруткой (длинный)** |
| **`Ctrl + Shift + X`** (или **`Ctrl + Shift + A`**) | **Обычный быстрый снимок выделенной области** |
| **`Esc`** | **Остановить автоскролл и сохранить / Отмена** |
| **`Колесо мыши`** | Плавный микро-шаг автоскролла |

> 💡 **Фоновый режим в трее:** при закрытии (крестик) или сворачивании окно программы прячется в системный трей возле часов и продолжает слушать горячие клавиши. Кликните правой кнопкой по иконке в трее, чтобы открыть меню или выйти.

---

## ✨ Возможности и особенности

* **Два режима съёмки:**
  * **`📜 С ПРОКРУТКОЙ`:** автоматическая плавная прокрутка и склейка контента в один длинный файл.
  * **`✂ ОБЫЧНЫЙ СНИМОК`:** быстрое выделение прямоугольной области с мгновенным копированием в буфер обмена (`Ctrl + V`) и автосохранением.
* **Сворачивание в системный трей:**
  * Иконка в области уведомлений Windows (возле часов).
  * Меню по правому клику (Открыть окно, Запустить снимок, Папка, Выход).
  * Всплывающие уведомления Windows при сохранении снимка.
* **Тёмный минималистичный дизайн в стиле `RazerDiamondbackController`:**
  * Красивые закруглённые кнопки без артефактов и пунктирных рамок.
  * Официальная векторная иконка Telegram в авторском бейдже **`✈ @Carist`**.
  * Фирменная иконка приложения в заголовке, трее и Проводнике.
* **High DPI Support:** Идеально чёткое отображение на 2K / 4K мониторах с масштабированием 125%, 150%, 200%.
